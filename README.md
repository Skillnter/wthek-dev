# WTHek Interactive Documentation Hub (`wthek-dev`)

Interactive documentation, RFC 7807 & RFC 9457 Problem Details sandbox, framework recipe builder, and HTTP status code explorer for **`@wthek`** and **`http-error-kit`**.

---

## Architecture

This documentation hub is engineered as an ultra-fast, zero-dependency, serverless static portal designed for immediate deployment on **GitHub Pages**:

- **Interactive RFC 9457 Playground**: Client-side JSON to RFC-compliant Problem Details transformer with real-time syntax highlighting.
- **Framework Recipe Builder**: Live boilerplate generator for Express, Fastify, Hono, Koa, NestJS, and Restify with 1-click `.cursorrules` export.
- **HTTP Status Code Explorer**: Fast, searchable standard status code and required headers directory powered by `http-response-status-code`.
- **Ecosystem Map**: Catalog of all 15 `@wthek` specialized packages.
